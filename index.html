준비하기

로그인하지 않아도 돼요. 하나씩 해 보고 끝나면 체크하세요.

잘 안 될 때

마이크로비트가 연결되지 않아요
  1. 열려 있는 브라우저(크롬, 엣지 등)를 모두 닫고, 엔트리 연결 프로그램(Entry_HW)도 닫아요.
  2. 마이크로비트 USB 선을 뽑았다가 다시 꽂아요.
  3. MICROBIT 드라이브에 바탕화면의 microbit2.hex를 다시 옮기고, 노란 불이 멈출 때까지 기다려요.
  4. 크롬을 열어 엔트리에 들어가고, 연결 프로그램 열기 → 마이크로비트 → 가장 큰 COM 순서로 다시 연결해요.
  5. 그래도 안 되면 바탕화면의 엔트리 오프라인 프로그램을 열어서 같은 방법으로 해 보세요.

Unexpected Error · Writing to COM port 창이 떠도 1번부터 다시 하면 돼요.

카메라 화면이 안 보여요

허용 창에서 차단을 눌렀다면, 주소창 왼쪽 자물쇠 모양 → 카메라 → 허용으로 바꾼 뒤 새로고침하세요.

웹캠 USB가 제대로 꽂혀 있는지, 다른 카메라가 선택되어 있지 않은지 확인하세요.

다른 탭이나 프로그램에서 카메라를 쓰고 있으면 끄세요.

손을 잘 못 찾아요

손을 카메라에서 30~60cm 거리에 두고, 손바닥이 카메라를 향하게 하세요. 뒤쪽 배경이 복잡하거나 어두우면 잘 못 찾아요.

안 쓰는 탭을 닫으면 인식이 빨라져요.

블록 이름은 엔트리 화면과 조금 다를 수 있어요. 비슷한 이름의 블록을 찾아 쓰면 돼요.

손등을 보이거나, 카메라에서 멀리 하거나, 손을 기울이면 AI가 다른 모양으로 알아볼 때가 있어요. 틀린 순간이 보이면 기억해 두었다가 제출할 때 적어 주세요.

생각해 보기: 버튼이나 빛 센서는 거의 틀리지 않는데, 손 인식 AI는 가끔 틀려요. 그렇다면 AI를 쓰는 장치를 만들 때 무엇을 조심해야 할까요?
얼굴과 몸은 소중한 개인정보예요

엔트리에는 얼굴 인식 AI도 있어요. 얼굴 사진은 누구인지 알아볼 수 있는 정보라서 함부로 찍거나 공유하면 안 돼요. 오늘 캡처를 제출할 때도 얼굴이 나오지 않게, 손만 보이게 찍어요.

제출하기: 결과 카드 만들기

완성한 작품을 캡처해 결과 카드로 만들어 제출해요.

제출 순서

  1. 학번을 써요.
  2. 엔트리에서 완성한 작품을 실행한 채로 Windows + Shift + S로 코드와 무대를 한 장에 캡처하고, 아래 칸에 넣어요.
  3. 결과 카드 만들기를 눌러요.
  4. 카드가 나타나면 선생님께 제출하기를 눌러요.
학년 1자리 + 반 2자리 + 번호 2자리예요. 3학년 1반 1번이면 30101, 3학년 12반 25번이면 31225.
적용한 확장
확장 단계에서 체크한 내용이 여기에 나와요.
캡처하기 전에 확인

캡처의 무대 화면에 얼굴이 나오면 안 돼요. 카메라에 손만 보이게 하고 찍으세요. 결과 카드는 반 친구들과 공개수업 참관자도 함께 봐요.

완성한 작품 캡처 (코드와 무대를 한 장에)
캡처한 뒤 이 화면 아무 곳에서 Ctrl + V를 누르면 들어가요
캡처 파일이 있다면 이 칸을 클릭해서 고를 수도 있어요

저장한 카드 파일(.png)을 선생님이 알려 준 공유 폴더나 클래스룸에 올리세요. 파일 이름은 바꾸지 않아도 돼요. 카드 안에 학번 정보가 들어 있어서 선생님 화면에서 자동으로 정리돼요.
